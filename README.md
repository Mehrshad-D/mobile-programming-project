# فیلم‌یاب

اپلیکیشن فارسی مدیریت و دنبال‌کردن فیلم و سریال، پیاده‌سازی‌شده با Flutter بر اساس صورت پروژه درس برنامه‌سازی موبایل.

## امکانات

- ثبت‌نام، ورود، خروج امن، نشست ۳۰ روزه، بازیابی رمز و ویرایش پروفایل
- ورود مهمان برای جست‌وجو و مشاهده جزئیات
- خانه شامل آثار محبوب، جدید، امتیاز بالا و ادامه تماشا
- جست‌وجو در عنوان، بازیگر، کارگردان و ژانر با تأخیر کنترل‌شده
- جزئیات کامل فیلم و سریال، فصل‌ها و قسمت‌ها
- وضعیت تماشا، علامت‌گذاری قسمت‌ها و محاسبه درصد پیشرفت
- امتیاز ۱ تا ۵، نظر و مخفی‌سازی نظرهای دارای اسپویل
- علاقه‌مندی، فهرست تماشا و فهرست‌های شخصی
- آمار فعالیت و زمان تقریبی تماشا
- ذخیره محلی حساب و تمام فعالیت‌ها
- کش استاندارد تصاویر Flutter، وضعیت بارگذاری و مدیریت خطاهای شبکه

## اجرا

```bash
flutter pub get
flutter run
```

در مدل پیشرفته، برنامه اطلاعات فیلم و سریال را فقط از بک‌اند اختصاصی پروژه دریافت می‌کند و کلید OMDb در اپلیکیشن قرار نمی‌گیرد. ابتدا بک‌اند پوشه `../backend` را اجرا کنید. آدرس پیش‌فرض شبیه‌ساز اندروید `http://10.0.2.2:8000/api/v1` است. برای سرور دیگر:

```bash
flutter run --dart-define=BACKEND_URL=https://api.example.com/api/v1
```

## ساختار

- `lib/models`: مدل‌های دامنه
- `lib/data`: داده نمونه قابل استفاده در حالت آفلاین/ارائه
- `lib/services`: ارتباط ناهمگام با API اختصاصی پروژه
- `lib/state`: منطق برنامه، احراز هویت و ذخیره محلی
- `lib/screens`: صفحات رابط کاربری
- `lib/widgets`: اجزای مشترک

رمز عبور محلی به‌صورت SHA-256 ذخیره می‌شود و متن ساده آن نوشته نمی‌شود. بک‌اند مستقل مدل پیشرفته، پایگاه داده سمت سرور، JWT، Argon2، نقش‌های کاربر/مدیر، کش OMDb و مستندات Swagger در پوشه `../backend` قرار دارند.
